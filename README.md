# Agent Skills Store

Публичная коллекция личных вспомогательных скиллов для AI-агентов. Репозиторий хранит общие инструкции и вспомогательные файлы, чтобы развивать их в одном месте и использовать на нескольких ноутбуках.

Коллекция может содержать скиллы разных направлений. Сейчас подготовлена только структура: сами скиллы будут добавляться отдельно.

## Структура

```text
skills/                 отдельные скиллы, каждый в своей папке
docs/setup.md           подключение и обновление на ноутбуках
CONTRIBUTING.md         добавление и изменение скиллов
PRIVACY.md              что разрешено публиковать
AGENTS.md               правила для агентов, работающих с репозиторием
SECURITY.md             действия при случайной публикации секрета
```

Будущий скилл размещается в `skills/<skill-name>/SKILL.md`. Скрипты, справочные материалы и ресурсы хранятся рядом с ним, если нужны для его работы. Имена папок — короткие, строчными латинскими буквами, слова через дефис.

## Начать работу

1. Клонируйте репозиторий на каждый ноутбук по [инструкции](docs/setup.md).
2. Подключите нужные скиллы способом, который поддерживает ваш агент.
3. Перед изменениями получите свежую версию; после изменений проверьте diff и отправьте коммит.

Токены, адресаты сообщений и настройки конкретного ноутбука хранятся отдельно. Репозиторий переносит скиллы; доступы к сервисам настраиваются на каждом устройстве.

## Публикация

Всё содержимое репозитория и история коммитов доступны публично. Перед добавлением файлов прочитайте [правила приватности](PRIVACY.md) и [правила изменений](CONTRIBUTING.md).

Лицензия пока не выбрана. Публичная доступность сама по себе не предоставляет открытую лицензию на использование и распространение. Перед добавлением чужих материалов проверяйте их условия.
