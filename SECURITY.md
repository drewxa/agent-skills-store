# Если опубликован секрет или личные данные

Не вставляйте обнаруженный секрет в публичный issue, pull request, комментарий или лог.

1. Если утёк ключ, токен или пароль, сразу отзовите или замените его в соответствующем сервисе. Удаление файла не отменяет доступ.
2. Уберите данные из текущей версии файлов. Замените их заглушками и настройкой через локальное окружение.
3. Проверьте историю Git, ветки, pull request, Actions, вложения и другие места, куда данные могли попасть. Очистку истории согласуйте с владельцем: она меняет коммиты и затрагивает клоны на других ноутбуках.
4. Для удаления чувствительных данных из GitHub используйте актуальную инструкцию GitHub и при необходимости его поддержку. Учтите форки и внешние копии: гарантировать их удаление нельзя.
5. После очистки обновите локальные клоны по согласованному порядку, чтобы не вернуть старые данные следующим push.

Добавление файла в `.gitignore` не удаляет его из истории и не прекращает отслеживание уже добавленного файла.
